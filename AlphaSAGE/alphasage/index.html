AlphaSAGE · 用 GFlowNet 做结构感知的 alpha 挖掘

Binqi Chen 等（北京大学 / 正仁量化 / Baruch College / UBC）· ICLR 2026 · arXiv:2509.25055v3 · github.com/BerkinChen/AlphaSAGE
核心主张：量化研究要的从来不是「那一个最好的因子」，而是「一组各不相同、都还不错的因子」—— 因为组合的价值来自低相关性。既然目标是分布，就别用最大化期望回报的 RL。

这不是调参问题。RL 的目标函数 max E[R] 的唯一最优解，就是把全部概率质量 放在奖励最高的那一个 α 上。你训练得越好，坍缩得越彻底。 GFlowNet 学的是分布：奖励 0.85 的被采到的概率约是 0.55 的 1.5 倍，但后者依然会被采到。
实测验证：code/gflownet_diversity_demo.py 用完全相同的策略参数化训练两种目标， 唯一变量是损失函数。结果：RL 有效发现 1/4 个模式（KL=3.30），GFlowNet 发现 4/4（KL=0.0000）。
论文没有验证的一环：核心因果链是「GFlowNet → 因子更多样 → 组合表现更好」。 起点和终点都验证了，但中间那一环从未被测量——全文没有一张「因子池内相关系数」的图。 存在一个说得通的替代解释：GFlowNet 的提升可能主要来自它是个更好的优化器（TB loss 的信用分配 比 PPO 更直接），而不是来自多样性。

AST + RGCN：不变性到底从哪来

论文说「AST 表示对语义上无关紧要的语法变体是不变的」。但这个不变性其实不来自 AST 本身， 而来自 GNN 邻居聚合的置换不变性——而置换不变性是把双刃剑。

同一个 alpha 的三种表示

(a) 公式 / (c) 逆波兰式（现有方法用的）
Log(TsStd($low, 10d))

RPN: BEG $low 10d TsStd Log SEP
(b) 表达式树（AlphaSAGE 用的）
Log │ TsStd ╱ ╲ $low 10d (数据边) (窗口边)

RGCN 而非普通 GCN 的理由：TsStd→$low（对哪个序列操作）和 TsStd→10d（用多长的窗口）是两种不同类型的关系，必须用不同的权重矩阵 W_r 处理。普通 GCN 对所有边一视同仁，做不到这一点。

各编码方案能不能区分「该区分的」

公式对语义应当实际
论文没说清的地方：「AST 表示对语法变体不变」这句话，实际上取决于你怎么定义 RGCN 的边类型。 论文只提了 data / window 这一个维度——它解决了窗口参数的问题， 但仍无法区分 Sub(a,b) 与 Sub(b,a)（邻居求和是置换不变的， 会把这两个判成相同，而这是错的）。复现时必须自己把交换律处理对。 实测见 code/alpha_ast_demo.py。

三项奖励与退火

R(α, T) = R_IC(α) + λ(T)·R_SA(α) + η(T)·R_NOV(α)， 两个权重都随训练线性退火到 0。拖动训练进度看权重变化。

0%
R_IC 权重（恒为 1）
λ(T) · R_SA　　λ_max = 1.0
η(T) · R_NOV　　η_max = 0.3

退火的两重作用：① 论文讲的「探索 → 利用」课程——早期先把表示学好、先铺开探索， 后期只剩纯粹的预测力；② 论文没讲的——R_NOV 依赖动态更新的 F_known， 本身带非平稳性。退火把非平稳性限制在训练早期，保证后期收敛到平稳目标 R = R_IC。

三项各司其职

R_IC E_d[Cov(α(X_d),y_d)/√(Var·Var)]
终端性能——「这个因子有用吗」
R_SA exp(−Σ_j w_ij · d_behav(α_i,α_j))
在嵌入空间找 K 近邻，看它们在行为空间离得多远。 用行为相似度监督结构嵌入——「我对搜索空间的理解对吗」
R_NOV 1 − maxα'∈F_known |IC(α, α')|
与已知因子低相关——「这个因子和已有的重复吗」。 最容易单独抄走的组件，不依赖 GFlowNet
实测发现：R_SA 与 R_NOV 存在结构性负耦合。
论文 §3.4 专门论证三项「由构造上对期望行为同号，没有显式的负耦合」。但注意—— R_SA 的 K 近邻正是从因子库里找的。一个行为上真正新颖的 alpha，它的嵌入近邻（都是池成员） 在行为上必然离它很远 → d_behav 大 → R_SA 被压低。

code/alpha_ast_demo.py 的量化检验（12 因子池分 3 个行为族，60 个新颖度连续变化的候选）： corr(R_SA, R_NOV) = −0.473，强负相关。而权重上 λ_max=1.0 是 η_max=0.3 的 3.3 倍。

保留意见：这是合成数据上的定性演示，不是证伪。但方向真实存在，且可能解释论文自己观察到的 「新颖性权重过大时性能下滑」——不是新颖性有害，而是它把 R_SA 挤掉了。
另一个张力：如果 GFlowNet 真的按 P ∝ R_IC 采样，理论上就已经能给出多样的因子， 为什么还需要 R_NOV 这个显式去重项？它的存在其实暗示了实践中 GFlowNet 的多样性还不够。 论文没有讨论这一点。

① GNN 是最大的单项提升： IC 0.046 → 0.070，SR −0.11 → 1.25。全文其他所有组件加起来的提升，都不如把 LSTM 换成 GNN。

② 只加 ES 会彻底失效： AR 从 3.63% 掉到 −0.47%，SR 变负。论文解释是「ES 需要更强的编码器」—— 合理但含糊，没有验证。ES 和 GNN 是耦合的，不能单独启用。

③ 熵正则让 RICIR 反而下降：0.614 → 0.583， 虽然 IC/AR/SR 都涨了。论文只说「整体最好」，没讨论这个回退。 可能是熵正则保留了一些排序稳定性较差、但与主流因子低相关的模式。

「所有相关性指标第一」的说法不准确。论文正文写 “ranks first on all correlation metrics”， 但表 1 里至少两处例外：CSI500 的 ICIR（AlphaAgent 0.396 > 0.379）、 CSI1000 的 RICIR（AlphaForge 0.742 > 0.736）。 另外 CSI500 上 IC 只赢 0.001（0.054 vs 0.053）——真正的差距在组合指标（SR 1.20 vs 0.93）。

但这其实支持论文的理论：单因子质量几乎打平，组合表现拉开明显差距， 恰恰说明价值来自因子间的低相关性。可惜论文没把这一点讲出来，也没测量它。
