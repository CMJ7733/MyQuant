## 1. 背景：什么是 alpha 挖掘

**Alpha** 是一个把历史市场数据映射成预测信号的确定性函数。在每个调仓时刻 `t`，alpha 给每只股票 `n` 打分 `s_{t,n}`，横截面标准化后转成组合信号——做多高分股、做空低分股。

```
组合收益：R_t = Σ_n w_{t,n} · r_{t+1,n}
```

预测质量用 **IC**（信号与次期收益的横截面相关系数）衡量。

关键在于：**生产系统维护的是一个 alpha 库，而不是单个 alpha**。库里的因子要既有预测力、又彼此低相关。这个"低相关"的要求，正是这篇论文的核心动机。

**当 alpha 表示成符号程序（如 AST）时，它是可解释、可审计的**——这是公式化因子相比端到端黑箱模型（如 [StockMixer](../stockmixer/)）的根本优势。

### 演进路线

```
人工假设驱动 → 遗传编程(GP/GA) → 强化学习(AlphaGen/AlphaQCM) → ★ GFlowNet
                                   ↘ 生成对抗(AlphaForge)
                                   ↘ LLM 驱动(AlphaAgent)
```

---

## 2. 问题陈述：RL 范式的三个结构性缺陷

论文把矛头指向"用 RL 做 alpha 挖掘"这条路线，指出三个**相互纠缠**的问题：

### 缺陷一：奖励稀疏（cold-start）

奖励（通常是 IC）**只有在整个公式构建完成后才能计算**。构建过程中的每一步都得不到反馈——就像下棋只在终局才知道输赢，且棋盘有天文数字级的分支。这导致探索低效且不稳定。

### 缺陷二：序列表示在语义上不充分

现有方法把 alpha 表达式当作**token 序列**（逆波兰式 RPN），用 LSTM 处理。问题是：

```
close + open   →   RPN: [close, open, Add]
open + close   →   RPN: [open, close, Add]
```

**语义完全等价，但序列不同**——LSTM 会把它们当作两个不同的对象。序列表示丢掉了公式的**层次结构**，而结构恰恰决定了 alpha 的行为。

论文用 Figure 1 展示了同一个 alpha 的三种形式：
```
(a) 公式:  Log(TsStd($low, 10d))
(b) 表达式树:        Log
                      │
                    TsStd
                    ╱    ╲
                 $low    10d
(c) RPN:  BEG $low 10d TsStd Log SEP
```

### 缺陷三：模式坍缩（mode collapse）

**这是最深刻的一点。** 标准 RL 的目标是 `max E[R]`，它天然驱使策略收敛到**单一最优模式**。但实践中需要的是**一组互不相关的 alpha**——

> 最大化期望回报 ⟺ 找到那一个最好的公式
> 实际需求 ⟺ 找到 50 个各不相同、都还不错的公式

**目标函数和实际需求直接冲突。**

---

## 3. 主要贡献

| 贡献 | 解决的缺陷 | 一句话 |
|---|---|---|
| **RGCN 结构感知编码器** | 缺陷二 | 在 AST 上做关系图卷积，对语义无关的语法变体不变 |
| **GFlowNet 生成框架** | 缺陷三 | 学 `P(α) ∝ R(α)` 而不是 `argmax R(α)`——**按奖励比例采样，天然多样** |
| **稠密多面奖励** | 缺陷一 | IC + 结构感知 + 新颖性，三项加权且随训练退火 |

---

## 4. 方法一句话

> 把公式当成图（不是序列）来编码，用 GFlowNet 按奖励比例采样（不是最大化），并且给每一步都造出反馈信号（不只在终局）。

**问题重构**：

```
旧范式（AlphaGen 等）：
  α*_new = argmax_α E[R(α|F)]，  R(α|F) = IC(c(X; F∪{α})) − IC(c(X; F))
  → 奖励依赖当前因子池 F，F 一更新奖励就变 → 非平稳 MDP
  → 只学到"贪心构造的单条路径"

新范式（AlphaSAGE）：
  学一个生成策略 P_θ(α) ∝ R(α)，∀α ∈ X
  → 直接建模整个高质量 alpha 空间上的分布
  → 从这个分布采样，自然得到多样且鲁棒的因子组合
```

**三个必须注意的细节**：

1. **只加 early stopping 会严重恶化**（AR 从 3.63% 掉到 **-0.47%**，SR 变负）。论文的解释是"ES 需要更强的编码器配合"。这说明 ES 不是一个独立的改进，而是与 GNN 耦合的。
2. **GNN 是最大的单项提升**（IC 0.046 → 0.070，SR -0.11 → 1.25）。结构感知编码是全文最有价值的一块。
3. **熵正则（ENT）让 RICIR 反而下降**（0.614 → 0.583）。论文只强调"整体最好"，没有讨论这个回退。

### 稳定性与敏感性

- **多种子**：CSI300 上跑多个随机种子，AlphaSAGE 对强基线的提升一致，排名顺序在各次运行中保持不变（附录）。
- **R_NOV 权重**：小到中等的取值下指标改善，之后进入一个宽平台，新颖性权重过大时开始下滑。
- **R_SA 权重**：改善基本是**单调**的，回撤稳定。
- 论文的总结是"响应平滑、没有突然的性能崩塌，说明对超参不敏感"。

## 6. 实验配置速查

| 项 | 值 |
|---|---|
| 数据集 | CSI300 / CSI500 / CSI1000（中国）、S&P500（美国） |
| 中国市场划分 | 训练 2010-01-01~2020-12-31 / 验证 2021 全年 / 测试 2022-01-01~2024-12-31 |
| 美国市场划分 | 训练 2010-01-01~2016-12-31 / 验证 2017 全年 / 测试 2018-01-01~2020-12-31 |
| 回测规则（CSI300/500） | 每交易日买入 top 20%，持有 20 天，**仅做多** |
| 回测规则（S&P500） | 每交易日买入 top 10%、卖空 bottom 10%，各持有 20 天，**多空组合** |
| 无风险利率 | `r_f = 0`（论文为简化和可比性而显式设定） |
| IC / RankIC 报告方式 | **取绝对值**（论文理由：因子符号可任意取反） |
| MaxLen | 20 个 token |
| Hidden Dim | 128 |
| RGCN 层数 | 2 |
| 熵系数 β | 0.01 |
| 学习率 | 1e-4 |
| SA 权重 λ_max | 1.0 |
| NOV 权重 η_max | 0.3 |
| 因子池容量 | 50 |
| 采样轨迹数 | 10000 / 20000 |

> ⚠️ **回测规则在两个市场之间不同**（长仓 vs 多空），这解释了为什么 S&P500 的 Sharpe（3~6）远高于 CSI（0.3~1.7）——**不要跨市场直接比较 SR 数值**。

## 7. 评价指标

**相关性指标**（越高越好）：
- **IC** = `E_d[ Cov(α(X_d), y_d) / √(Var(α(X_d))·Var(y_d)) ]`，横截面预测力
- **ICIR** = `E_d[ρ_d] / √Var_d(ρ_d)`，预测力的时序稳定性
- **RIC / RICIR**：把 Pearson 换成基于排名的相关系数

**组合指标**：
- **AR**（年化收益）= `K · E_d[R_d]`，K=252
- **MDD**（最大回撤）= `−max_t(1 − W_t / max_{u≤t} W_u)`，刻画尾部风险，方差捕捉不到
- **SR**（年化夏普）= `√K · E_d[R_d − r_f] / √Var_d(R_d − r_f)`
