## 0. 符号表

| 符号 | 含义 |

## 2. 问题重构（§3.1）—— 全文的起点

**旧范式**（AlphaGen 等 RL 方法）：

```
α*_new = argmax_{α∈X} E[ R(α|F) ]
其中  R(α|F) = IC(c(X; F ∪ {α})) − IC(c(X; F))
```

奖励定义为「加入因子池后，组合模型 `c(·)` 性能的边际提升」。这个设计很聪明——直接优化协同性。但有两个后果：

1. **非平稳 MDP**：`F_t` 一更新，所有 alpha 的奖励都变了；
2. **只学到一条贪心路径**：它鼓励单个组合内部的协同，但**没有学到"所有高质量 alpha"的全局分布**。

**新范式**（AlphaSAGE）：

```
学一个生成策略  P_θ(α) ∝ R(α),   ∀α ∈ X
```

不再问"下一个该加哪个因子"，而是问"高质量因子的分布长什么样"。从这个分布采样，天然得到多样的组合。

## 3. 组件一：GFlowNet 生成器（§3.2）

### 3.1 状态空间是一个 DAG

```
状态 s ∈ S    ：部分构建的 AST。s₀ 是空树。
               终止状态 = 完整且合法的 AST，构成 X ⊂ S
动作 a ∈ A    ：往部分 AST 的一个开放叶节点上加一个 token（算子或特征）
               ★ 根据当前状态 s，非法动作被掩码，token 从掩码后的分布中采样
完整轨迹      ：构成合法表达式树的路径。只有这样的轨迹才是终止的、可评估的
```

**动作掩码是必须的**——它保证了每条轨迹要么是合法公式，要么被早停机制截断，不会产生垃圾输出。这是符号生成任务相对于自由文本生成的优势。

### 3.2 早停机制

```
p = Len(s_t) / MaxLen                              …… (Eq. 4)
```

当**当前栈已经构成一个合法表达式**时，以概率 `p` 停止生成。`Len(s_t)` 是当前节点数，`MaxLen = 20`（论文取值）。

**动机**：防止表达式无限增长，也防止超过 MaxLen 后被强行截断成非法状态。

**行为**：表达式越长，停止概率越高——这是一个隐式的复杂度惩罚（奥卡姆剃刀）。

> ⚠️ 消融显示**单独加 ES 会严重恶化**（AR 3.63% → -0.47%，SR 变负）。论文说"ES 需要更强的编码器配合"。所以 **ES 不是独立可用的组件**，必须和 GNN 一起上。

### 3.3 流匹配条件与 Trajectory Balance 损失

GFlowNet 同时学**前向策略** `P_F(s_{t+1}|s_t; θ)`（构造）和**后向策略** `P_B(s_t|s_{t+1}; θ)`（解构），训练目标是让流量匹配：

```
P(α) = Σ_{τ: s_n=α} P_F(τ) = R(α) / Z          …… (Eq. 5)
其中 Z = Σ_{α'∈X} R(α')  是可学习的配分函数
```

用 **Trajectory Balance (TB) 损失**：

```
L_TB(τ) = ( log Z_θ + Σ_{t=1}^n log P_F(s_t|s_{t-1};θ)
                    − log R(s_n)
                    − Σ_{t=1}^n log P_B(s_{t-1}|s_t;θ) )²        …… (Eq. 6)
```

**读法**：括号里是「从起点走到 α 的前向流量的对数」减去「奖励 + 后向流量的对数」。理想情况下两者相等，损失为 0。平方保证了双向惩罚。

**为什么用 TB 而不是别的 GFlowNet 损失**（如 Flow Matching、Detailed Balance）：论文说 TB "特别适合我们的场景，因为它关注完整轨迹"。这符合 alpha 生成的特点——**只有完整公式才能计算 IC**，中间状态没有直接的奖励，所以基于完整轨迹的信用分配更自然。

> ⚠️ **`log Z_θ` 是一个全局标量**，被所有轨迹共享。它估计不准会污染**每一条**轨迹的损失。实践中通常给 `log Z_θ` 单独设一个更大的学习率。论文没有提这一点，但这是 GFlowNet 训练的常见坑。

## 4. 组件二：RGCN 结构感知编码器（§3.3）

### 4.1 为什么必须用 AST

```
close + open  →  RPN: [BEG, $close, $open, Add, SEP]
open + close  →  RPN: [BEG, $open, $close, Add, SEP]
```

序列不同，语义等价。论文原话：*"这种（AST）表示对语义上无关紧要的语法变体是不变的。"*

### 4.2 为什么必须用 RGCN 而不是普通 GCN

AST 里的边有**不同的类型**：

```
        TsStd
       ╱     ╲
    $low     10d
   （数据边）（参数边）
```

`TsStd → $low` 和 `TsStd → 10d` 在语义上完全不同——一个是"对哪个序列做操作"，一个是"用多长的窗口"。普通 GCN 对所有边用同一个权重矩阵，无法区分。

RGCN 为**每种关系类型 r** 学一个独立的 `W_r`：

```
h_v^(l) = ReLU( Σ_{r∈R} Σ_{u∈N_r(v)} (1/c_{v,r}) · W_r^(l) · h_u^(l-1)
                + W_0^(l) · h_v^(l-1) )                            …… (Eq. 7)

e_α = MaxPooling( { h_v^(L) }_{v∈V_α} )                            …… (Eq. 8)
```

- `R`：关系类型集合
- `N_r(v)`：通过关系 r 与 v 相连的邻居
- `c_{v,r}`：归一化常数（如 `|N_r(v)|`）
- `W_0^(l)`：自环变换矩阵
- 图嵌入用 **MaxPooling**（不是 mean）—— 保留最显著的节点特征

**论文超参**：RGCN 2 层，hidden dim 128。2 层意味着每个节点能看到 2 跳邻居——对深度通常 3~5 的 AST 来说，这覆盖了局部子结构但不是全图。

**消融**：GNN 是最大的单项提升（IC 0.046 → 0.070，SR -0.11 → 1.25）。

## 5. 组件三：多面奖励函数（§3.3 末 + §3.4）

### 5.1 R_IC —— 终端性能

```
R_IC(α) = IC(α, y) = E_d[ Cov(α(X_d), y_d) / √(Var(α(X_d))·Var(y_d)) ]    …… (Eq. 12)
```

标准的横截面 IC。

> ⚠️ 附录说明"报告 IC/RankIC 的**绝对值**，因为因子符号在取反意义下是任意的"。复现时必须确认是 `|E_d[ρ_d]|`（先平均再取绝对值，合理）还是 `E_d[|ρ_d|]`（**会系统性虚高**）。从公式写法看应该是前者，但文字没到无歧义的程度。

### 5.2 R_SA —— 结构-行为对齐（稠密信号）

**目标**：让结构嵌入相似的 alpha，行为也相似。

```
行为距离（Z 是横截面标准化后的因子值时序）：
  d_behav(α_i, α_j) = (1/D) · Σ_{d=1}^D ( Z_i(d) − Z_j(d) )²          …… (Eq. 9)

嵌入空间的 KNN softmax 权重：
  w_ij = exp(−‖e_i − e_j‖²) / Σ_{k∈N_K(α_i)} exp(−‖e_i − e_k‖²)       …… (Eq. 10)

奖励：
  R_SA(α_i) = exp( − Σ_{j∈N_K(α_i)} w_ij · d_behav(α_i, α_j) )        …… (Eq. 11)
```

**读法**：在**嵌入空间**里找 K 近邻，看它们在**行为空间**里离得多远。嵌入邻居行为也接近 → `d_behav` 小 → `R_SA` 接近 1。

这是一个**自监督的表示对齐信号**：用行为相似度去监督结构嵌入。它同时提供了稠密反馈（不必等公式建完，中间嵌入也在被优化）。

**消融定位**：SA 主要改善排序稳定性（RICIR 0.554 → 0.566）和收紧回撤（MDD -19.4% → -17.6%），对绝对 IC 几乎无影响（0.070 → 0.071）。符合"整理搜索空间几何结构"的定位。

### 5.3 R_NOV —— 新颖性

```
R_NOV(α) = 1 − max_{α' ∈ F_known} |IC(α, α')|                          …… (Eq. 13)
```

惩罚与**动态更新的已知高质量因子库** `F_known` 的相似度。

**这是最容易单独抄走的组件**——不依赖 GFlowNet，可以直接加到任何现有搜索框架里。

### 5.4 组合与退火

```
R(α, T) = R_IC(α) + λ(T)·R_SA(α) + η(T)·R_NOV(α)                       …… (Eq. 14)

λ(T) = (1 − T/T_anneal) · λ_max      λ_max = 1.0
η(T) = (1 − T/T_anneal) · η_max      η_max = 0.3
```

**退火含义**：早期重视表示学习和探索，后期只剩纯粹的预测力。典型的"探索 → 利用"课程。

**论文特意论证三项不冲突**：三者对"好行为"同号——预测力高、结构-行为对齐好、新颖性高，都让总奖励上升。`R_NOV` 惩罚的是与因子库的冗余，不是与 `R_IC` 竞争。

### 5.5 熵正则

```
L_ENT = −E_{τ~P_F}[ Σ_{t=0}^{n-1} H(π_θ(·|s_t)) ]                       …… (Eq. 15)
L_final = E_{τ~P_F}[ L_TB(τ) ] + β · L_ENT                              …… (Eq. 16)
```

`β = 0.01`。注意这是**动作层面**的熵，与 GFlowNet 自带的**分布层面**多样性是两个不同尺度的探索机制。

> ⚠️ 消融显示加 ENT 后 **RICIR 反而从 0.614 掉到 0.583**，虽然 IC/AR/SR 都涨了。论文只说"整体最好"，没讨论这个回退。

## 6. 组件四：因子组合（§3.5）

**直接沿用 AlphaForge 的方法**：

- 不固定一组静态因子，而是**每期动态重选**；
- 筛出近期有效的 alpha，通过**简单线性回归**重新加权；
- 得到一个时变的 "Mega-Alpha"。

论文的理由：*"这个设计的优势在于它能快速适应 regime shift，同时保持可解释性：因子贡献是透明的，且通过丢弃陈旧或冗余的信号来避免过拟合。相比复杂的非线性组合器，这个方法在鲁棒性、效率和解释清晰度之间取得了平衡。"*

**对复现的意义**：组合阶段与 AlphaForge 完全一致，所以两者的性能差异**纯粹来自生成阶段**。这让对比很干净。

## 7. 完整算法（论文 Algorithm 1 整理）

```
输入: GFN 参数 θ；概率缓冲 B_prob ← ∅；嵌入缓冲 B_emb ← ∅；因子池 F ← ∅

for step t = 1, 2, ..., T_max:
    1.  解析当前状态 s_t → AST ast_t
    2.  计算状态嵌入  e_t ← f_GNN(ast_t)                      # Eq. 8
    3.  输出动作分布  π_θ(·|ast_t)；追加到 B_prob
    4.  if rand() ≥ p_es(s_t):                                # 早停判定
    5.      a_t ← SEP
        else:
    6.      从 π_θ(·|ast_t) 采样/选择 a_t ∈ A（非法动作已掩码）

    7.  if a_t == SEP:                                        # ===== 终止 =====
    8.      构建表达式  α ← BuildExpr(s_t)
    9.      计算因子值  z ← ComputeAlpha(α, X)
   10.      相关性奖励  R_IC ← IC(z, y)                        # Eq. 12
   11.      新颖性奖励  R_NOV ← Novelty(z, F)                  # Eq. 13
   12.      对终端嵌入 e_t 在池嵌入中做 KNN
   13.      构建距离权重矩阵 W ← Dist2Weight(N) 与行为相似度 sim
   14.      结构奖励    R_SA ← SAReward(sim)                   # Eq. 11
   15.      总奖励      R ← Combine(R_IC, R_SA, R_NOV, t)      # Eq. 14
   16.      if PassThreshold(R):
   17.          F ← F ∪ {α};  把 e_t 追加到 B_emb
   18.      L_TB ← TrajectoryBalance(B_prob, R)                # Eq. 6
   19.      L_ent ← EntropyReg(B_prob);  清空 B_prob           # Eq. 15
   20.      L_final ← L_TB + λ_ent · L_ent                     # Eq. 16
   21.      θ ← θ − η ∇_θ L_final
   22.      重置 S_{t+1} ← InitState();  清空 B_prob
        else:                                                 # ===== 继续 =====
   23.      状态转移 S_{t+1} ← Transition(S_t, a_t)

return F
```

**注意第 12–14 步**：KNN 检索是在**每次生成完一个 alpha 时**做的，需要维护嵌入缓冲 `B_emb`，且 `d_behav` 要算完整的因子值时间序列。**这是主要的计算瓶颈。**

## 8. 超参设置（论文表 4）

| 名称 | 说明 | 值 |
|---|---|---|
| Max Length | 状态 `s_t` 中最大 token 数 | **20** |
| Hidden Dim | 隐状态维度 | **128** |
| Encoder Layer | RGCN 编码器层数 | **2** |
| Entropy Coef | `L_ENT` 的权重 β | **0.01** |
| Learning Rate | 优化 θ 的学习率 | **1e-4** |
| SA Weight | `R_SA` 的权重 λ_max | **1.0** |
| NOV Weight | `R_NOV` 的权重 η_max | **0.3** |
| Pool Capacity | 因子池最大 alpha 数 | **50** |
| Episodes | 轨迹采样实例数 | **10000 / 20000** |

**敏感性**（论文 Figure 4，CSI300）：
- `R_NOV` 权重：小到中等时指标改善，之后进入**宽平台**，新颖性主导时开始下滑；
- `R_SA` 权重：改善基本**单调**，回撤稳定；
- 总体"响应平滑，没有突然崩塌"→ 对超参不敏感，调参负担低。

## 9. 实现陷阱

### 9.1 `log Z_θ` 的学习率

TB loss 里 `log Z_θ` 是一个被**所有轨迹共享**的全局标量。它收敛慢会污染每一条轨迹的梯度。**标准做法是给它单独设一个大 10~100 倍的学习率。** 论文没提，但这是 GFlowNet 训练最常见的坑。

### 9.2 动作掩码必须严格

非法动作（如给一个已满的算子再加参数、在需要窗口长度的位置放特征）必须在采样前掩掉。掩码不严会产生非法 AST，`BuildExpr` 崩溃或产生垃圾因子。

**同时注意**：掩码后要**重新归一化**概率分布，否则 `log P_F` 算出来是错的，TB loss 直接失效。

### 9.3 Early Stopping 不能单独用

消融第二行：只加 ES，AR 从 3.63% 掉到 -0.47%，SR 变负。**ES 必须和 GNN 编码器一起上。**

### 9.4 `R_SA` 的计算成本

每生成一个 alpha 都要：
1. 算完整的因子值时间序列 `Z_i ∈ R^{D×N}`；
2. 在嵌入缓冲里做 KNN；
3. 对 K 个邻居算 `d_behav`（每个都是 `D×N` 的逐元素运算）。

**这是主要瓶颈。** 实践中需要：缓存因子值、限制 `B_emb` 大小、用近似 KNN。

### 9.5 `F_known` 的更新引入了部分非平稳性

`R_NOV` 依赖动态更新的 `F_known`。论文批评 RL 的非平稳 MDP，但自己也有这个性质——只是程度轻（只有一个分项，且后期退火到 0）。**如果你去掉退火，非平稳性会显著增强。**

### 9.6 IC 取绝对值的实现

必须确认是 `|E_d[ρ_d]|` 还是 `E_d[|ρ_d|]`。后者会让**零预测力的随机因子也得到正分数**，是严重的评估偏差。

### 9.7 两个市场的回测规则不同

- CSI300/500：买入 top 20%，持有 20 天，**仅做多**
- S&P500：top 10% 做多 + bottom 10% 做空，各持有 20 天，**多空**

**不要跨市场比较 SR 数值**——S&P500 的 SR 高达 6.32 主要是多空组合对冲了市场风险，而不是因子质量更高（IC 反而更低，0.052 vs CSI1000 的 0.076）。

### 9.8 没有交易成本

全文未提手续费、印花税、冲击成本。20 天持有期换手率不高（约每天 1/20 仓位），但 A 股的成本依然可观。**复现时务必自己加上。**

## 10. 复现风险清单

| 风险 | 影响 | 缓解 |
|---|---|---|
| `log Z_θ` 学习率与其他参数相同 | TB loss 收敛慢/不收敛 | 单独设更大的学习率 |
| 动作掩码后未重新归一化 | `log P_F` 错误，TB loss 失效 | 掩码 → 重归一化 → 采样 |
| 单独启用 ES 而无 GNN | AR 变负 | 两者必须一起 |
| `R_SA` 未做缓存 | 训练慢数量级 | 缓存因子值 + 近似 KNN |
| `E_d[\|ρ_d\|]` 而非 `\|E_d[ρ_d]\|` | IC 系统性虚高 | 确认公式实现 |
| 未做退火（λ, η 恒定） | 后期探索过度，收敛差 | 按 Eq. 14 实现线性退火 |
| 跨市场比较 SR | 结论错误 | 注意长仓 vs 多空的差异 |
| 未加交易成本 | AR/SR 虚高 | 加入手续费与冲击成本 |
| 只跑一个种子 | 结论不稳 | 论文做了多种子验证，照做 |
| **未测量因子多样性** | 无法验证核心主张 | 记录因子池内平均 \|IC\| 相关系数 |

## 11. 与 AlphaGen 的关键差异（一表看清）

| | AlphaGen (RL) | AlphaSAGE (GFlowNet) |
|---|---|---|
| 目标 | `argmax E[R(α\|F)]` | `P_θ(α) ∝ R(α)` |
| 奖励 | 组合边际提升（依赖 F） | IC + SA + NOV（主要依赖 α 自身） |
| MDP | 非平稳 | 基本平稳（NOV 项部分依赖 F_known） |
| 表示 | RPN 序列 + LSTM | AST + RGCN |
| 反馈 | 只在终端 | 终端 + 结构对齐（稠密） |
| 多样性 | 靠非平稳奖励间接实现 | 目标函数内建 |
| 输出 | 一条贪心构造路径 | 高奖励空间的采样器 |
| CSI300 结果 | IC 0.058, SR 0.76 | IC 0.079, SR 1.71 |
