## 基础题（5 题）

### 1. 论文指出 RL 应用于 alpha 挖掘有哪三个结构性缺陷？分别用什么方法解决？

<details>
<summary>答案</summary>

| 缺陷 | 具体问题 | 解决方案 |
|---|---|---|
| **① 奖励稀疏** | 奖励（IC）**只有在整个公式构建完成后**才能计算，中间步骤无反馈，探索低效不稳定（"cold-start"） | **稠密多面奖励** `R_IC + λ(T)·R_SA + η(T)·R_NOV`，其中 `R_SA` 提供结构层面的中间信号 |
| **② 序列表示语义不足** | 用 RPN token 序列 + LSTM，捕捉不到公式的层次结构；`close+open` 与 `open+close` 语义等价但序列不同 | **AST + RGCN 结构感知编码器**，对语义无关的语法变体不变 |
| **③ 模式坍缩** | 标准 RL 的 `max E[R]` 天然驱使策略收敛到**单一最优模式**，违背"需要一组低相关 alpha"的实践需求 | **GFlowNet**：学 `P_θ(α) ∝ R(α)`，按奖励比例采样而非最大化 |

论文强调这三个问题是**相互纠缠的（interconnected）**——表示不足会让稀疏奖励更难利用，模式坍缩又让稀疏奖励下的探索雪上加霜。

</details>

### 2. GFlowNet 的目标与标准 RL 的目标有什么本质区别？

<details>
<summary>答案</summary>

```
标准 RL:      maximize  E_{α~π_θ}[ R(α) ]
GFlowNet:     P_θ(α) ∝ R(α),   ∀α ∈ X
```

**本质区别**：

- RL 的目标**唯一最优解是一个确定性策略**——把所有概率质量放在奖励最高的那个 `α*` 上。整个机制（策略梯度、贪心改进）都在推着它往那走。
- GFlowNet 学的是一个**分布**。奖励 0.08 的 alpha 被采到的概率是奖励 0.04 的两倍，但后者**依然会被采到**。

**为什么这对 alpha 挖掘至关重要**：

生产系统维护的是**因子库**，从中选一批组合成信号。组合的价值来自因子之间的**低相关性**——两个 IC=0.05 但相关系数 0.95 的因子，合起来价值约等于一个；两个 IC=0.04 但相关系数 0.1 的因子，合起来远超任何一个。

「找一个最好的」和「找一批各不相同的」是**两个不同的目标**，而 RL 只能做前者。

论文原话：*"标准 RL 的最大化期望回报目标本质上驱使策略走向单一最优模式，直接违背了对一组非相关 alpha 组合的实践需求。"*

**实现上**：GFlowNet 学前向策略 `P_F(s_{t+1}|s_t)` 和后向策略 `P_B(s_t|s_{t+1})`，通过匹配流量达成 `P(α) = R(α)/Z`，`Z = Σ_{α'} R(α')` 是可学习的配分函数。

</details>

### 3. AlphaSAGE 的状态、动作、终止条件是什么？早停机制怎么工作？

<details>
<summary>答案</summary>

**状态空间是一个有向无环图（DAG）**：

- **状态 `s ∈ S`**：部分构建的 AST。`s₀` 是空树。终止状态是**完整且合法**的 AST，构成 `X ⊂ S`。
- **动作 `a ∈ A`**：往部分 AST 的一个**开放叶节点**上添加一个 token（算子或特征）。**非法动作被掩码**，token 从掩码后的分布中采样。
- **完整轨迹**：构成合法表达式树的路径。**只有这样的轨迹是终止的、可评估的。**

**早停机制**（Eq. 4）：

```
p = Len(s_t) / MaxLen
```

当**当前栈已构成合法表达式**时，以概率 `p` 停止。`Len(s_t)` 是当前节点数，`MaxLen = 20`。

**动机**：① 防止表达式无限增长；② 防止超过 MaxLen 后被强行截断成**非法状态**。

**行为特征**：表达式越长，停止概率越高——隐式的复杂度惩罚（奥卡姆剃刀）。论文说它"在探索更长表达式与产出语法合法公式的效率之间取得平衡"。

> ⚠️ 消融显示**单独加 ES 会严重恶化**（AR 3.63% → -0.47%，SR 变负 -0.11）。论文解释是"ES 需要更强的编码器配合"。ES 不是独立可用的组件。

</details>

### 5. 三项奖励分别是什么？为什么要退火？

<details>
<summary>答案</summary>

```
R(α, T) = R_IC(α) + λ(T)·R_SA(α) + η(T)·R_NOV(α)        …… (Eq. 14)
```

| 项 | 公式 | 作用 |
|---|---|---|
| **R_IC** | `E_d[Cov(α(X_d),y_d)/√(Var·Var)]` | 终端性能：预测力 |
| **R_SA** | `exp(−Σ_j w_ij·d_behav(α_i,α_j))` | 结构-行为对齐（稠密信号） |
| **R_NOV** | `1 − max_{α'∈F_known}\|IC(α,α')\|` | 新颖性：惩罚与已知因子的冗余 |

**退火**：
```
λ(T) = (1 − T/T_anneal)·λ_max      λ_max = 1.0
η(T) = (1 − T/T_anneal)·η_max      η_max = 0.3
```

两个权重都**随训练线性衰减到 0**。

**为什么退火**：这是一个"探索 → 利用"课程。

- **早期**：SA/NOV 权重大 → 先把结构嵌入学好（让搜索空间几何结构合理）、先铺开探索（避免过早聚集）；
- **后期**：权重降到 0，只剩 `R_IC` → **收敛到纯粹追求预测力**。

不退火的话，后期模型会持续为"新颖"牺牲"有效"——得到一堆彼此不同但都没预测力的因子。

**论文特意论证三项不冲突**：三者对好行为同号——预测力高、结构-行为对齐好、新颖性高，都让总奖励上升。`R_NOV` 惩罚的是与**因子库**的冗余，不是与 `R_IC` 竞争。

</details>

## 进阶题（5 题）

### 6. 为什么必须用 AST 而不是 RPN 序列？为什么必须用 RGCN 而不是普通 GCN？

<details>
<summary>答案</summary>

**AST vs RPN**：

```
close + open   →   RPN: [BEG, $close, $open, Add, SEP]
open + close   →   RPN: [BEG, $open, $close, Add, SEP]
```

序列不同，**语义完全等价**。LSTM 会给它们不同的表示，模型必须浪费容量去学"这两个其实一样"。

论文原话：*"这种方法未能捕捉数学表达式的层次结构，把逻辑等价的公式（例如 close+open 和 open+close）当作不同的序列。"*

AST 表示**对语义上无关紧要的语法变体是不变的**。

**RGCN vs GCN**：

AST 里的边有**不同的类型**：

```
        TsStd
       ╱     ╲
    $low     10d
   （数据边）（窗口参数边）
```

`TsStd → $low`（"对哪个序列操作"）和 `TsStd → 10d`（"用多长的窗口"）语义完全不同。普通 GCN 对所有边用同一个 `W`，无法区分。

RGCN 为每种关系类型学独立的 `W_r`：

```
h_v^(l) = ReLU( Σ_{r∈R} Σ_{u∈N_r(v)} (1/c_{v,r})·W_r^(l)·h_u^(l-1) + W_0^(l)·h_v^(l-1) )
e_α = MaxPooling({h_v^(L)}_{v∈V_α})
```

论文原话：*"这对于区分（例如）时序算子与特征之间的边、与时序算子和它的窗口长度之间的边，是至关重要的。"*

**消融证据**：GNN 是最大的单项提升——IC 0.046 → 0.070，SR -0.11 → 1.25。**全文其他所有组件加起来的提升，都不如把 LSTM 换成 GNN。**

细节：图嵌入用 **MaxPooling**（不是 mean），保留最显著的节点特征；RGCN 2 层，hidden 128。

</details>

### 7. 详细解释 `R_SA` 的计算过程。它为什么算"稠密"信号？

<details>
<summary>答案</summary>

**目标**：确保学到的嵌入不只"结构感知"，还要**能预测 alpha 的实际行为**——结构相似的 alpha 应表现出相似的行为模式。

**三步**：

**① 行为距离**（Eq. 9）
```
d_behav(α_i, α_j) = (1/D) · Σ_{d=1}^D ( Z_i(d) − Z_j(d) )²
```
`Z_i ∈ R^{D×N}` 是 α_i 横截面标准化后的输出时序。衡量两个因子在**实际数值上**多接近。

**② 嵌入空间的 KNN 权重**（Eq. 10）
```
w_ij = exp(−‖e_i − e_j‖²) / Σ_{k∈N_K(α_i)} exp(−‖e_i − e_k‖²),   j ∈ N_K(α_i)
```
在**嵌入空间**找 K 近邻，softmax 归一化的高斯核做权重。

**③ 奖励**（Eq. 11）
```
R_SA(α_i) = exp( − Σ_{j∈N_K(α_i)} w_ij · d_behav(α_i, α_j) )
```

**读法**：在**嵌入空间**找邻居，看它们在**行为空间**离得多远。
- 嵌入邻居行为也接近 → `d_behav` 小 → `R_SA` → 1（好）
- 嵌入邻居行为差很远 → `d_behav` 大 → `R_SA` → 0（嵌入学错了）

**为什么算"稠密"**：

`R_SA` 虽然也在终端计算，但它的**梯度会流回 RGCN 编码器**，直接塑造**所有中间状态**的嵌入表示。

- `R_IC` 只说"这个完整公式好不好"；
- `R_SA` 说"你对公式空间的**表示**对不对"——这个信号对每个中间状态都有意义。

本质是一个**自监督的表示对齐信号**：用行为相似度监督结构嵌入。

**消融定位**：SA 主要改善**排序稳定性**（RICIR 0.554 → 0.566）和**收紧回撤**（MDD -19.4% → -17.6%），对绝对 IC 几乎无影响（0.070 → 0.071）。完全符合"整理搜索空间几何结构"的定位——不直接找更好的因子，而是让搜索更有方向感。

**代价**：这是训练的主要瓶颈。每生成一个 alpha 都要算完整因子值时序、做 KNN、对 K 个邻居算 `d_behav`。

</details>

### 8. Trajectory Balance 损失是什么？为什么选它？`log Z_θ` 有什么坑？

<details>
<summary>答案</summary>

**流匹配条件**（Eq. 5）：
```
P(α) = Σ_{τ: s_n=α} P_F(τ) = R(α) / Z,     Z = Σ_{α'∈X} R(α')
```

**Trajectory Balance 损失**（Eq. 6）：
```
L_TB(τ) = ( log Z_θ + Σ_{t=1}^n log P_F(s_t|s_{t-1};θ)
                    − log R(s_n)
                    − Σ_{t=1}^n log P_B(s_{t-1}|s_t;θ) )²
```

**读法**：括号里是「从起点走到 α 的前向流量的对数」减去「奖励 + 后向流量的对数」。理想情况两者相等，损失为 0。平方保证双向惩罚。

**为什么选 TB**：论文说 TB "特别适合我们的场景，因为它关注完整轨迹"。这符合 alpha 生成的特点——**只有完整公式才能计算 IC**，中间状态没有直接奖励，所以基于完整轨迹的信用分配最自然。

对比其他 GFlowNet 损失：
- **Flow Matching**：要求每个状态的入流=出流，需要中间状态的流量估计；
- **Detailed Balance**：逐边匹配，需要中间奖励；
- **Trajectory Balance**：只需要终端奖励 + 整条轨迹的策略概率。✓

**`log Z_θ` 的坑**：

`Z_θ` 是一个**被所有轨迹共享的全局标量**（近似配分函数）。它有两个问题：

1. **收敛慢会污染每一条轨迹**。因为它出现在每个 `L_TB(τ)` 里，估计不准会给所有梯度加一个共同的偏置。
2. **数值范围极大**。`Z = Σ_α R(α)` 在组合空间上求和，量级可能跨越很多数量级。

**标准做法**：给 `log Z_θ` 单独设一个大 10~100 倍的学习率。这是 GFlowNet 训练最常见的实践技巧。

**论文没有提这一点**——复现时如果发现 TB loss 不收敛，先查这里。

</details>

**可惜的是，论文没有把这一点讲出来**。如果加一张"因子池内平均相关系数"的对比图，这个论证会强得多——而目前多样性这个核心卖点，**从未被直接测量过**。

### 10. 消融表里有两个"反常"的行。找出来并解释。

<details>
<summary>答案</summary>

**反常 ①：只加 Early Stopping 会严重恶化**

| ES | GNN | SA | NOV | ENT | IC | ICIR | AR | MDD | SR |
|---|---|---|---|---|---|---|---|---|---|
| ✗ | ✗ | ✗ | ✗ | ✗ | 0.048 | 0.393 | 3.63% | -22.9% | 0.72 |
| ✓ | ✗ | ✗ | ✗ | ✗ | 0.046 | 0.313 | **-0.47%** | -24.8% | **-0.11** |

AR 从 3.63% 掉到 **负数**，SR 变成 -0.11。这不是小幅退化，是**彻底失效**。

论文的解释：*"仅添加早停（ES）反而有害，说明 ES 需要更强的编码器。"*

这个解释合理但含糊。**我的推测**（论文未验证）：`p = Len(s_t)/MaxLen` 让短表达式被大量采样，而 LSTM 对短序列的表示区分度不足——一堆长度 3~5 的表达式在 LSTM 嵌入空间里挤成一团，策略无法区分好坏，奖励信号退化成噪声。换成 RGCN 后，即使是短 AST 也有清晰的结构签名，问题消失。

**结论**：ES 和 GNN 是**耦合的**，不能单独启用。

**反常 ②：熵正则让 RICIR 下降**

| ES | GNN | SA | NOV | ENT | IC | RIC | **RICIR** | AR | SR |
|---|---|---|---|---|---|---|---|---|---|
| ✓ | ✓ | ✓ | ✓ | ✗ | 0.075 | 0.092 | **0.614** | 6.77% | 1.53 |
| ✓ | ✓ | ✓ | ✓ | ✓ | 0.079 | 0.094 | **0.583** | 7.62% | 1.71 |

加了 ENT 后 IC、RIC、AR、SR 全涨，**唯独 RICIR 从 0.614 掉到 0.583**。

论文只说"最终熵正则器带来最好的整体结果"，**没有讨论这个回退**。

**可能的解释**：熵正则鼓励策略保留更多模式，其中一些模式的因子**排序稳定性较差**（在某些时期表现好、某些时期差）。这拉低了 RICIR（排序预测力的时序稳定性），但因为它们与主流因子低相关，在组合中依然贡献了收益（AR/SR 上升）。

**这是一个真实的权衡**：用排序的时序稳定性，换取更高的绝对收益和多样性。值得讨论而不是略过。

</details>

## 高阶题（5 题）

### 11. 论文批评 RL 的"非平稳 MDP"，但 AlphaSAGE 自己有没有非平稳性？

<details>
<summary>答案</summary>

**有，而且论文没有明说。**

**AlphaGen 的非平稳性**：
```
R(α|F) = IC(c(X; F ∪ {α})) − IC(c(X; F))
```
奖励定义为"加入因子池后组合模型性能的边际提升"。池子 `F_t` 一更新，**所有** alpha 的奖励都变了。论文明确批评：*"这个表述创造了一个非平稳的马尔可夫决策过程。"*

**AlphaSAGE 的非平稳性**：
```
R_NOV(α) = 1 − max_{α' ∈ F_known} |IC(α, α')|
```
`F_known` 是**动态更新的**——每当发现一个高质量因子（`PassThreshold(R)`），就加入库中。这意味着 `R_NOV` 也会随训练变化。

**但程度差别很大**：

| | AlphaGen | AlphaSAGE |
|---|---|---|
| 受影响的奖励部分 | **全部** | 只有 `R_NOV` 一项 |
| 权重 | 100% | `η(T) ≤ 0.3`，且**线性退火到 0** |
| 后期行为 | 依然完全非平稳 | 退火后 `R = R_IC`，**完全平稳** |

**所以退火在这里有第二重作用**（论文只强调了"探索→利用"这一重）：**它把非平稳性限制在训练早期，保证后期收敛到一个平稳目标。**

这是个聪明但没被论文讲出来的设计。如果你复现时去掉退火（让 `η` 恒定），非平稳性会显著增强，训练稳定性可能下降。

**一个可以追问的点**：既然 GFlowNet 本身就该产生多样的因子，**为什么还需要 `R_NOV` 这个显式的去重压力？** 理论上按 `R_IC` 比例采样就够了。`R_NOV` 的存在其实暗示了 GFlowNet 在实践中的多样性不足。论文没有讨论这个张力。

</details>

### 12. 论文的核心因果链是什么？哪一环没有被验证？你会怎么补这个实验？

<details>
<summary>答案</summary>

**核心因果链**：

```
用 GFlowNet（学分布而非最大化）
        ↓  ①
生成的因子更多样（彼此低相关）
        ↓  ②
组合后表现更好（更高 AR / SR，更低 MDD）
```

**验证情况**：
- ✅ 起点：确实用了 GFlowNet（方法部分）
- ❌ **中间环节 ①：从未被测量**
- ✅ 终点：组合表现确实更好（表 1）

**问题**：整篇论文没有一张图/一个数字直接展示"AlphaSAGE 生成的因子比 AlphaGen 更多样"。

**为什么这重要**：存在一个完全说得通的**替代解释**——

> GFlowNet 的提升可能主要来自它是一个**更好的优化器**（TB loss 的信用分配比 PPO 的策略梯度更直接、方差更小），而不是来自多样性。

如果是这样，那"目标函数与需求错配"这个漂亮的理论故事就是**事后叙事**，真正起作用的是优化效率。这两种解释导向完全不同的后续研究方向。

**我会补的实验**（按性价比排序）：

**实验 A（最直接，成本极低）**：
> 横轴训练步数，纵轴"因子池内两两 |IC| 相关系数的平均值"，对比 AlphaSAGE / AlphaGen / AlphaQCM / AlphaForge。

如果 AlphaSAGE 的曲线显著更低 → 核心主张成立。
如果几条线差不多 → 性能提升需要另一套解释。

**实验 B（区分两种解释）**：
> 把 AlphaSAGE 的 GFlowNet 换成 PPO，但**保留** AST+RGCN 编码器和三项奖励。

如果性能大幅下降 → GFlowNet 本身重要。
如果性能接近 → 提升主要来自编码器和奖励设计，GFlowNet 是锦上添花。

**实验 C（验证多样性的下游价值）**：
> 固定因子池大小，人为过滤掉高相关因子（相关系数 > 0.7 的只留一个），看各方法的性能变化。

如果 AlphaGen 的性能大幅下降而 AlphaSAGE 不变 → 说明 AlphaGen 的性能依赖冗余因子。

**实验 D（覆盖度）**：
> 把生成的因子嵌入用 t-SNE 降到 2 维，可视化对比各方法的覆盖范围。

定性但直观，适合放进论文正文。

</details>

### 13. `R_SA` 的思路（用行为相似度监督结构嵌入）能泛化到哪些别的问题？

<details>
<summary>答案</summary>

**抽象出来的模式**：

> 当你有一个「**程序/结构** → **行为/输出**」的映射，且想学一个好的结构嵌入时，可以用"行为相似度"作为自监督信号——**要求结构空间的近邻在行为空间也接近**。

这个模式的适用条件：
1. 有一个离散的结构对象（程序、图、公式、分子）；
2. 每个对象可以被"执行"得到一个行为签名（数值输出、性质向量）；
3. 结构相似 ≠ 行为相似（否则不需要学）；
4. 行为评估比结构评估贵，但不是贵到不能做。

**可以直接迁移的场景**：

| 领域 | 结构 | 行为签名 | 应用 |
|---|---|---|---|
| **代码生成** | AST / IR | 在测试输入上的输出向量 | 让语义等价的代码嵌入接近；改进代码检索、去重 |
| **符号回归** | 表达式树 | 在采样点上的函数值 | 与 AlphaSAGE 几乎同构 |
| **分子设计** | 分子图 | 理化性质向量（logP、溶解度…） | 让性质相似的分子嵌入接近 |
| **电路设计** | 网表 | 仿真波形 | 加速设计空间探索 |
| **神经架构搜索** | 架构 DAG | 在小代理任务上的学习曲线 | 用便宜的行为签名对齐架构嵌入 |
| **数据库查询优化** | 查询计划树 | 在样本数据上的执行统计 | 计划相似度学习 |

**关键设计选择**（从 AlphaSAGE 学到的）：

1. **用 KNN 而不是全部配对**：`O(n²)` 的配对计算不可行，只看嵌入空间的 K 近邻；
2. **softmax 加权而不是均等**：越近的邻居权重越大（Eq. 10）；
3. **用 `exp(−·)` 把距离转成 [0,1] 的奖励**：便于与其他奖励项相加；
4. **退火**：早期重要（先把表示学对），后期降权（专注最终目标）。

**一个值得注意的变体**：AlphaSAGE 把它做成**奖励项**（因为要接入 GFlowNet 的奖励框架）。在纯监督/自监督场景下，更自然的做法是把它做成**对比学习损失**——正样本 = 行为相似的对，负样本 = 行为不同的对。效果类似但梯度信号更强。

</details>

### 14. 如果让你扩展这篇论文，你会做什么？给出三个方向并说明预期收益。

<details>
<summary>答案</summary>

**方向 1：测量并优化多样性（低成本，补上核心缺口）**

如问题 12 所述，论文的核心主张没有被直接验证。

具体做法：
- 记录训练过程中因子池内的平均 `|IC|` 相关系数，与所有基线对比；
- 进一步：把"因子池的有效秩"（相关矩阵的特征值分布熵）作为一个**新的评价指标**加入表格；
- 更进一步：直接把它作为一个奖励项或早停准则。

**预期收益**：(a) 验证或推翻核心主张；(b) 为整个 alpha 挖掘领域提供一个缺失的标准指标——目前所有论文都只报 IC 和组合指标，没人报多样性。**这本身就可能是一篇独立的短文。**

---

**方向 2：处理 IC 奖励的噪声（中成本，理论价值高）**

**问题**：GFlowNet 学的是 `P(α) ∝ R(α)`。但 `R_IC` 本身**噪声极大**——同一个因子在不同时段的 IC 能差一倍。这意味着模型在学一个**带噪声的目标分布**。

这在 GFlowNet 的原始应用（分子设计）里不是大问题——分子的理化性质是确定性的。但在金融里，奖励本身就是一个高方差的统计量。

具体做法：
- 用 bootstrap / 分时段采样估计 `R_IC` 的置信区间，把奖励改成"下置信界"（悲观估计）；
- 或者改成 `R = E[IC] − κ·std(IC)`，即 ICIR 风格的风险调整奖励；
- 理论上分析：当 `R` 有噪声 `ε` 时，`P ∝ R + ε` 学到的分布与 `P ∝ R` 差多少。

**预期收益**：(a) 这是 GFlowNet 应用于金融的**根本性问题**，论文完全没碰；(b) 可能直接提升 ICIR（论文在 CSI500 上正好输在这个指标）；(c) 有独立的理论贡献。

---

**方向 3：跨市场迁移（中高成本，实用价值最高）**

论文在中美两个市场分别训练。但**因子的结构知识应该是可迁移的**——`TsStd($low, 10d)` 这类波动率因子在哪个市场都是波动率因子。

具体做法：
- 在 CSI300 上预训练 RGCN 编码器 + GFlowNet 策略；
- 在 S&P500 上只微调奖励相关部分（`R_IC` 的计算），冻结或小学习率更新编码器；
- 对比：从零训练 vs 迁移。

**预期收益**：(a) 直接检验"结构感知编码器学到的是通用的公式语义"这个隐含假设；(b) 如果成立，新市场的冷启动成本大幅降低——这在实际业务里价值极高（进入一个新市场不用重头搜）；(c) 如果不成立，说明编码器学到的是市场特定的东西，那"结构感知"的叙事需要修正。

**顺带的洞察**：[AlphaBench](../alphabench/) 发现了一个相关现象——在 CSI300 上微调的 LLM 迁移到 S&P500 效果不错（pairwise selection 0.44 → 0.64），反向则差（S&P500 → CSI300 只有 0.50）。他们的解释是"中国市场规则更严格、摩擦更多、散户驱动的波动更强，产生了更清晰、更频繁的噪声型模式，给模型更多样的结构案例学习"。**这个不对称性值得在 AlphaSAGE 上验证。**

---

**优先级**：方向 1 最先做（几乎零成本，直接补论文缺口），方向 3 次之（业务价值最高），方向 2 最后（最难但理论贡献最大）。

</details>

### 15. 综合评价：这篇论文最强的地方和最弱的地方分别是什么？

<details>
<summary>答案</summary>

**最强的地方：问题诊断。**

「标准 RL 的目标函数与 alpha 挖掘的实际需求存在结构性错配」——这个诊断非常准，而且**它的价值超过论文提出的任何具体技术**。

理由：
1. **它解释了一个长期存在但没被清晰命名的现象**。所有做因子挖掘的人都知道"搜出来的因子容易同质化"，但之前的处理方式都是打补丁（加多样性惩罚、用非平稳奖励），没人指出这是**目标函数本身选错了**。
2. **它可迁移**。任何"需要一组多样的高质量解"的组合优化问题都适用同样的论证——分子设计、NAS、程序合成。诊断比药方更通用。
3. **它导向了一个已有的成熟工具**（GFlowNet），而不是发明一个新方法。这是好的研究品味——先把问题看对，工具往往已经存在。

**次强的地方：AST + RGCN 的必要性论证。**

"`TsStd → $low` 是数据边，`TsStd → 10d` 是参数边，必须用不同的权重矩阵"——这个论证很具体，不是泛泛地说"图比序列好"。而且消融数据完美支持（GNN 是最大单项提升）。

---

**最弱的地方：核心主张缺少直接证据。**

论文的因果链是「GFlowNet → 多样性 → 更好的组合」，但**中间那一环从未被测量**。整篇论文没有一张"因子池内相关系数"的图。

这不是吹毛求疵，因为存在一个完全说得通的替代解释：GFlowNet 的提升可能主要来自它是一个**更好的优化器**，而不是来自多样性。补这个实验的成本极低（问题 12 的实验 A），但它没被做。

**次弱的地方：几处表述超出了数据支持。**

1. "ranks first on all correlation metrics" —— 至少两处例外（CSI500 ICIR、CSI1000 RICIR）；
2. 消融里 ENT 让 RICIR 下降，论文只说"整体最好"没讨论；
3. "ES 需要更强的编码器"这个解释含糊，没有验证；
4. IC 取绝对值的具体实现没写清楚（`|E[ρ]|` 还是 `E[|ρ|]`，后者会系统性虚高）。

---

**总评**：

这是一篇**理论动机远强于实证严谨性**的论文。它提出了一个正确且重要的问题重构，工程实现扎实（RGCN、TB loss、退火课程都用得对），实验覆盖两个市场四个数据集，还做了多种子和敏感性分析——这些都是加分项。

但它对自己最核心的卖点缺少直接测量，几处措辞超出了数据支持。**如果我是审稿人，我会给出"接受但要求补充多样性度量实验"的意见**——因为那个实验几乎零成本，而它能把论文从"效果好"提升到"知道为什么好"。

**对读者的建议**：读这篇论文，重点吸收**问题诊断**和**AST+RGCN 的设计论证**；对"GFlowNet 带来多样性因而更好"这条因果链保持一分保留，直到看到直接证据。

</details>
