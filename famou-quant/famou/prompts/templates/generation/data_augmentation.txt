## Data Augmentation Techniques

Select appropriate techniques based on task type:

**For Images**:
- Geometric: horizontal/vertical flips, rotation, scaling, translation, cropping, elastic transform
- Color: brightness, contrast, saturation, hue adjustments, Gaussian noise
- Advanced: MixUp, CutMix, Mosaic, Random Erasing
- Note: Use libraries like albumentations, torchvision.transforms

**For Text**:
- Synonym replacement, random deletion, random swap
- Back-translation (translate to another language and back)
- Noise injection (spelling errors, word dropout)
- Contextual augmentation using pretrained language models

**For Tabular**:
- SMOTE (Synthetic Minority Over-sampling Technique)
- Random noise injection
- Feature mixing/interpolation
- Bootstrap sampling

**For Audio**:
- Time stretching, pitch shifting
- Background noise addition
- Specular augmentation
- MixUp

**For Time Series**:
- Time warping
- Scaling, rotation
- Noise injection
- Window slicing

Key principles:
- **Keep labels consistent**: Ensure augmentation doesn't change the ground truth
- **Appropriate intensity**: Don't over-augment (e.g., extreme rotations that make images unrecognizable)
- **Domain-aware**: Use augmentations that make sense for the data type
- **Performance vs. augmentation**: Balance training time gains vs. augmentation overhead
