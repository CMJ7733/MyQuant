## Data Cleaning and Preprocessing Techniques

Select appropriate techniques based on data issues:

**Handling Missing Values**:
- Simple: mean/median/mode imputation
- Advanced: KNN imputation, iterative imputation, model-based imputation

**Handling Outliers**:
- Statistical: z-score, IQR method, isolation forest
- Domain-based: manual thresholding, business rules
- Robust methods: winsorization, clipping

**Handling Imbalanced Data**:
- Undersampling: Random, NearMiss, Tomek links
- Oversampling: Random oversampling, SMOTE, ADASYN
- Hybrid: Combine both methods
- Class weights: Adjust model loss function

**Data Validation**:
- Range checks: Values within expected bounds
- Type checks: Correct data types
- Consistency checks: Logical relationships between features
- Duplicate removal: Remove redundant samples

**Feature Preprocessing**:
- Scaling: StandardScaler, MinMaxScaler, RobustScaler
- Encoding: One-hot, label encoding, target encoding
- Normalization: L1, L2 normalization
- Binning/discretization: Continuous to categorical
