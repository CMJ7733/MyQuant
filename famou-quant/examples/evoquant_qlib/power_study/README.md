## 2. 三个对论文有直接价值的量化事实

- **配对设计是 1 年窗可行的前提**：父子日度 RankIC 相关 ≈0.94，配对方差仅为独立样本设计的
  **5–8%**（≈13–20× 方差缩减）。不配对的 Δ_min ≈ 0.036 —— 在 1 年窗内什么都测不出来。
  这直接支撑论文 "paired evidence construction" 支柱。
- **自相关温和，不是杀手**：ρ₁ 中位 0.094，N 228 → N_eff ≈ 190；纸面担心的
  "金融序列自相关砍掉有效样本" 只造成 ~10–20% 侵蚀。
- **seed 重训噪声地板 ≈ 0.003–0.007**：同配置仅换 seed，1 年窗 mean RankIC 差可达 0.007
  （本次 base seed2026 恰好是 5 个 seed 里最弱的）。→ **gate 的 null 不是 "d=0" 而是
  "d ~ seed 重训分布" 的复合 null**；小于该地板的 "改进" 与重训噪声不可分，
  gate 最小有意义效应量应设在地板之上。这本身是可写进论文的 measurement。

## 3. 诚实披露（写论文时不得省略）

a. **假阳性**：10 个 NULL 对里 1 个 t=1.72 > 1.645（观测 10% vs 名义 5%；对间共享模型非独立，
   小样本下不矛盾）。实际 gate 用 e-process/anytime-valid 边界，有效门槛更高（≈2.5–3），
   该对不会被误晋升；1.645 是固定-N 检验的乐观下界。
b. **Δ_min=0.0091 是固定-N 口径**：e-process 的 anytime-valid 代价约 1.3–1.8× →
   实际可检测 Δ ≈ 0.012–0.016。**设计含义**：gate 应按"晋升窗末一次性结算 e-value /
   block 化分组序贯"设计，而非逐日连续监控，把代价压回接近固定-N。
c. **leaves180 是恒等变异**：num_leaves 210→180 在重正则（λ₁=206, λ₂=581）+ 早停(iter 15)下
   长出的树完全相同 → 预测逐位一致。对功效测量是退化对（已从统计中剔除意义），
   但对论文是好例子：**存在改配置不改函数的中性变异，gate 应拒绝（无改进证据）而非晋升**。
d. **GAP 对方向反了**：浅树（leaves=8, depth=3, 早停 iter 119）在 promo 2015 上**强于**官方配置
   (+0.0114, t=2.33)。"已知弱模型"假设失败——2015 股灾年+重正则下浅模型泛化更好。
   该对仍完成使命：证明 Δ≈0.011 的真实差异确实可检出（t=2.33），与 Δ_min 估计自洽。
e. **单 episode、单市场态**：promo=2015 是极端波动年（单模型日度 RankIC std≈0.15）；
   其他年份 std(d_t) 可能更小（Δ_min 更好）。多窗验证等 E2–E5 解封后在论文实验里自然覆盖，
   此处不提前触碰。

## 4. 对 W2 gate 设计的输入参数（由本实测冻结）

| 参数 | 实测值 |
|---|---|
| std(d_t) | 0.051（设计取保守 0.06） |
| ρ₁ | ~0.10 → 1 年窗 N_eff ≈ 190 |
| 固定-N Δ_min | 0.009 |
| anytime 代价后目标可检测 Δ | 0.012–0.016 → **gate 效应量目标定 0.015** |
| seed 噪声地板 | 0.005（复合 null 的尺度参数） |
| 证据结算方式 | 晋升窗 block 化（月度块 ×12）而非逐日，压缩 anytime 代价 |
